-CONCEITOS BASICOS DE HTML;

O HTML eh uma formataçao de texto muito usada na web, juntamente das linguagens de programaçao como por exemplo python e java.
HT de HTML significa Hiper Texto, fazendo referencia as coisas que foram chamadas anteriormente. Que esta sendo dito no ML, que significa
linguagem de marcaçao, que sao as tags.

-EXEMPLOS;

  • imagem
  • video
  • texto

Ou seja, HTML nada mais eh do que um grande interpretador de texto, a um grosso modo. pois ele pega as tags e o
navegador interpreta esse tipo de informaçao, mostrando ao usuario; como eh no caso das tags acima, essa formataçao
ocorre de duas formas, pelo cabeçario e pelo corpo do texto.

  • BODY: O CORPO DO TEXTO;

Aqui no head eh onde fica todas as informaçoes que somente o navegador le, ou seja, sao informacoes que nao aparecem para o usuario;
dentre essas informaçoes que nao aparecem temos os meta dados.

  • BODY: O CORPO DO TEXTO;

Dentre as informaçoes que aparecem pro usuario temos o body, tudo dentro dessa tag eh o que sera exibido para o usuario interagir com o programa.

META DADOS;

Ao digitar HTML:5+enter aparece toda a estrutura usada para programar qualquer coisa em HTML,
com algumas meta tags adicionais que voçe precisa colocar.

TAGS ADCIONAIS DO HTML+5;

  • 1 - meta name="description" content="x"
  • 2 - meta name="keywords" content="a, b, c"
  • 3 - meta name="author" content="x"

A primeira meta tag adicional eh a descriçao do seu site para as buscas que o navegador faz. A segunda meta tag eh
so uma selecao de palavras chaves para o navegador encontrar mais facilmente teu site. Enquanto a terceira meta
tag eh so o nome do autor que fez aquele site.

PARAGRAFOS;

Como o nome sugere eles criam paragrafos de texto para o usuario ler e dentro desses paragrafos podemos
pintar o texto com varias tags. Os paragrafos ficam dentro do body.

  • b para deixar palavras em negrito
  • strong para palavras que necessitam de enfases
  • i para deixar as palavras em italico
  • u para sublinhar as palavras

ELEMENTOS DE TITULOS;

Para colocar titulos em seu site usamos a tag h e os numeros que vem acompanhado dela, como h1, h2, h3... sao para dizer o grau de iportancia
daquele titulo, nunca jamais usamos a tag h para deixrar o texto bonito, usamos somente para determinar o grau de importancia daquele bloco de texto.
