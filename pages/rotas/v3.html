-CONCEITOS BÁSICOS DE HTML;

O HTML é uma formatação de texto muito usada na web, juntamente das linguagens de programação como por exemplo python e java.
HT de HTML significa Hiper Texto, fazendo referência às coisas que foram chamadas anteriormente. Que está sendo dito no ML, que significa
linguagem de marcação, que são as tags.

-EXEMPLOS;

  • imagem
  • vídeo
  • texto

Ou seja, HTML nada mais é do que um grande interpretador de texto. Pois ele pega as tags e o
navegador interpreta esse tipo de informação, mostrando ao usuário; como é no caso das tags acima, essa formatação
ocorre de duas formas, pelo cabeçalho e pelo corpo do texto.

BODY: O CORPO DO TEXTO;

Aqui no head é onde ficam todas as informações que somente o navegador lê, ou seja, são informações que não aparecem para o usuário;
dentre essas informações que não aparecem temos os meta dados.

Dentre as informações que aparecem pro usuário temos o body, tudo dentro dessa tag é o que será exibido para o usuário interagir com o programa.

META DADOS;

Ao digitar HTML:5+enter aparece toda a estrutura usada para programar qualquer coisa em HTML,
com algumas meta tags adicionais que você precisa colocar.

TAGS ADICIONAIS DO HTML+5;

  • 1 - meta name="description" content="x"
  • 2 - meta name="keywords" content="a, b, c"
  • 3 - meta name="author" content="x"

A primeira meta tag adicional é a descrição do seu site para as buscas que o navegador faz. A segunda meta tag é
uma seleção de palavras chaves para o navegador encontrar mais facilmente seu site. Enquanto a terceira meta
tag é só o nome do autor que fez aquele site.

PARÁGRAFOS;

Como o nome sugere eles criam parágrafos de texto para o usuário ler e dentro desses parágrafos podemos
pintar o texto com várias tags. Os parágrafos ficam dentro do body.

  • b para deixar palavras em negrito
  • strong para palavras que necessitam de ênfase
  • i para deixar as palavras em itálico
  • u para sublinhar as palavras

ELEMENTOS DE TÍTULOS;

Para colocar títulos em seu site usamos a tag h e os números que vêm acompanhados dela, como h1, h2, h3... são para dizer o grau de importância
daquele título, nunca usamos a tag h para deixar o texto bonito, usamos somente para determinar o grau de importância daquele bloco de texto.

Os títulos de h só vão até 6.
